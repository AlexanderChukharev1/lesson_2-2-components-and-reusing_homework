# Инструкции помощникам

Единые правила находятся в [AGENTS.md](../AGENTS.md), требования для студента в [README.md](../README.md). Здесь хранится [указатель на них](policy.md), а не отдельная версия правил.

Точки входа в проект:

| Файл | Назначение |
| --- | --- |
| `AGENTS.md` | Основные инструкции помощнику |
| `CLAUDE.md` | Указатель для Claude Code |
| `.cursor/rules/learning.mdc` | Правило Cursor с `alwaysApply: true` |
| `.cursorrules` | Указатель для прежнего формата Cursor |
| `.github/copilot-instructions.md` | Инструкции GitHub Copilot |
| `GEMINI.md` | Подключение правил для Gemini CLI |

Форматы сверены с документацией [Cursor](https://docs.cursor.com/context/rules-for-ai) и [Gemini CLI](https://geminicli.com/docs/cli/gemini-md/). При изменении условий обновляйте единые правила, а здесь проверяйте ссылки. Не создавайте параллельных разрешений на выполнение отдельных бонусов, конфигураций или отчёта.

Служебные файлы задают разрешённую помощь, но не гарантируют соблюдение правил внешним сервисом. Самостоятельность проверяется объяснением и изменением знакомого фрагмента по условию. Реакции конкретных помощников в этом пакете не тестировались.
